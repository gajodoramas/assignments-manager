# Assignments Manager

![Java](https://img.shields.io/badge/Java-18+-000000?logo=openjdk&logoColor=white)
![Java Swing](https://img.shields.io/badge/Java%20Swing-18+-000000?logo=openjdk&logoColor=white)
![MariaDB](https://img.shields.io/badge/MariaDB-3+-000000?logo=mariadb)
![Flatlaf](https://img.shields.io/badge/Flatlaf-2.6-000000)

**Assignments Manager** is an application that allows teachers to create assignments for
studies.

The project was built using **Java**, **Java Swing**, **MariaDB** and **Flatlaf**.

> [!NOTE]
> Developed as a student project (2021 - 2023) under time constraints,
> this application provides core functionality but remains a prototype.
> Please be aware that you may encounter bugs or non-production-ready code.
